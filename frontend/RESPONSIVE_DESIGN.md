# レスポンシブデザイン対応

Trippyは、デスクトップ、タブレット、モバイル端末のすべてで快適に使えるよう設計されています。

## ブレークポイント

Tailwind CSSのデフォルトブレークポイントを使用：

- **モバイル**: < 640px（ベースライン）
- **タブレット (sm)**: ≥ 640px
- **デスクトップ (md)**: ≥ 768px
- **大画面 (lg)**: ≥ 1024px

## レスポンシブ対応の主な改善点

### 1. ヘッダー

- **モバイル**: 
  - タイトル: 3xl (30px)
  - サブテキスト: text-sm (14px)
  - マージン: mb-6 (24px)
- **デスクトップ**:
  - タイトル: 4xl (36px)
  - サブテキスト: text-base (16px)
  - マージン: mb-8 (32px)

### 2. コントロールボタン

- **モバイル**: 
  - 縦並び（flex-col）
  - ボタンはフルワイド（flex-1）
  - text-sm (14px)
- **タブレット以上**:
  - 横並び（flex-row）
  - 通常幅
  - text-base (16px)

### 3. 地点カード

- **モバイル**:
  - パディング: p-3 (12px)
  - スペース: space-y-2 (8px)
  - 移動情報: 縦並び（flex-col）
  - 入力欄: フルワイド
- **デスクトップ**:
  - パディング: p-4 (16px)
  - スペース: space-y-3 (12px)
  - 移動情報: 横並び（flex-row）

### 4. ルート検索モーダル

- **モバイル**:
  - 最大高さ: 90vh
  - パディング: p-4 (16px)
  - テキスト: text-base (16px)
  - ボタンパディング: p-3 (12px)
- **デスクトップ**:
  - 最大高さ: 80vh
  - パディング: p-6 (24px)
  - テキスト: text-lg (18px)
  - ボタンパディング: p-4 (16px)

### 5. 地図表示

- **モバイル**: 高さ 400px
- **デスクトップ**: 高さ 500px

### 6. タイムライン

- **モバイル**:
  - タイトル: text-2xl (24px)
  - マーカーサイズ: w-8 h-8 (32px)
  - パディング: p-4 (16px)
  - テキスト: text-xs (12px)
- **デスクトップ**:
  - タイトル: text-3xl (30px)
  - マーカーサイズ: w-10 h-10 (40px)
  - パディング: p-6 (24px)
  - テキスト: text-sm (14px)

## タッチ最適化

- すべてのボタンは最小タップ領域44x44px以上
- テキスト入力欄はモバイルで大きめのフォントサイズ（16px以上）でズーム防止
- スワイプ操作には対応していませんが、すべてタップ可能

## テキストの折り返し

- 長い地点名は`break-words`で折り返し
- 距離・時間表示は`whitespace-nowrap`で改行なし
- メモ欄も`break-words`対応

## スペーシング

- モバイルでは全体的に余白を小さく（space-y-2, gap-2）
- デスクトップでは余白を大きく（space-y-4, gap-4）
- `min-w-0`を使用して長いテキストのオーバーフロー防止

## フォントサイズの一貫性

| 要素 | モバイル | デスクトップ |
|------|----------|--------------|
| ページタイトル | text-3xl (30px) | text-4xl (36px) |
| セクションタイトル | text-xl (20px) | text-2xl (24px) |
| カードタイトル | text-base (16px) | text-lg (18px) |
| 本文 | text-sm (14px) | text-base (16px) |
| 補足テキスト | text-xs (12px) | text-sm (14px) |

## テスト方法

### ブラウザの開発者ツール

1. Chrome/Firefox/Safariの開発者ツールを開く
2. デバイスツールバーを有効化（Ctrl+Shift+M / Cmd+Shift+M）
3. 以下のデバイスでテスト：
   - iPhone SE (375px)
   - iPhone 12/13 Pro (390px)
   - iPad (768px)
   - Desktop (1024px+)

### 実機テスト

- iOS Safari
- Android Chrome
- タブレット
