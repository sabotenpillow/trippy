# Trippy - 旅行経路共有アプリ

旅行の経由地や目的地、それぞれの滞在時間、移動方法と移動時間をURLで共有できるアプリです。

## 機能

- ✈️ 複数日の旅行プラン作成
- 📍 地点の追加・削除・並び替え
- ⏱️ 滞在時間と移動時間の設定
- 🚆 移動方法の記録
- 🔗 URLで簡単共有（バックエンド不要）
- 👀 編集モードとプレビューモードの切り替え

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド
npm run build
```

開発サーバーは http://localhost:3000 で起動します。

## 技術スタック

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **React 19**

## 使い方

1. **プランの作成**
   - 「新規作成」ボタンで新しい旅行プランを開始
   - タイトルを入力
   - 「地点を追加」で各地点の情報を入力
   - 「日を追加」で複数日の旅程を作成

2. **地点の設定**
   - 地点名、滞在時間、メモを入力
   - ▲▼ボタンで順序を変更
   - 2番目以降の地点には移動情報を設定

3. **共有**
   - 「📋 共有リンクをコピー」でURLをコピー
   - URLをシェアするだけで誰でも閲覧可能

4. **プレビュー**
   - 「プレビュー」タブでタイムライン表示を確認
   - 各日の合計時間も表示

## データ構造

プランデータはURLクエリパラメータにBase64エンコードして保存されます。
バックエンドやデータベースは不要で、完全にクライアント側で動作します。
