# Google AdSense セットアップガイド

Trippyで広告収益を得るためのGoogle AdSenseの設定方法です。

## バックエンドは必要？

**不要です！** Google AdSenseは完全にクライアントサイドで動作します。
JavaScriptタグを埋め込むだけで広告が表示されます。

## セットアップ手順

### 1. Google AdSenseアカウントを作成

1. https://www.google.com/adsense/ にアクセス
2. Googleアカウントでログイン
3. 「ご利用開始」をクリック
4. サイト情報を入力（例: https://yourdomain.com）
5. 審査を申請

### 2. サイトをAdSenseに追加

1. AdSenseダッシュボードで「サイト」→「サイトを追加」
2. サイトのURLを入力
3. 確認コードを取得（自動的に`<head>`に挿入されます）

### 3. クライアントIDを取得

AdSenseが承認されると、クライアントIDが発行されます。
形式: `ca-pub-xxxxxxxxxxxxxxxx`

### 4. 環境変数を設定

`.env.local`ファイルにクライアントIDを追加：

```bash
NEXT_PUBLIC_ADSENSE_CLIENT_ID=ca-pub-xxxxxxxxxxxxxxxx
```

### 5. 広告ユニットを作成

1. AdSenseダッシュボードで「広告」→「広告ユニットごと」
2. 「ディスプレイ広告」を選択
3. 広告の名前とタイプを設定
4. 広告スロットIDを取得（例: `1234567890`）

### 6. 広告スロットIDを設定

`app/page.tsx`の`adSlot`プロパティを実際の広告スロットIDに変更：

```typescript
<AdSense
  adSlot="1234567890" // ← 実際の広告スロットIDに変更
  adFormat="auto"
/>
```

### 7. サーバーを再起動

```bash
npm run dev
```

## 広告の配置

現在の配置：

1. **編集モード**: 「日を追加」ボタンの上
2. **プレビューモード**: タイムラインの下部

### カスタマイズ方法

`app/page.tsx`で`<AdSense />`コンポーネントを追加/移動できます：

```typescript
<AdSense
  adSlot="your-ad-slot-id"
  adFormat="auto"          // 'auto', 'fluid', 'rectangle', 'horizontal', 'vertical'
  fullWidthResponsive={true} // レスポンシブ対応
  className="my-6"         // スタイリング
/>
```

## 広告フォーマット

| フォーマット | 説明 | 推奨場所 |
|------------|------|---------|
| `auto` | 自動サイズ調整 | ほとんどの場所 |
| `fluid` | コンテンツに合わせて変化 | コンテンツ内 |
| `rectangle` | 長方形 | サイドバー |
| `horizontal` | 横長バナー | ページ上部/下部 |
| `vertical` | 縦長 | サイドバー |

## 開発モード

開発環境（`NODE_ENV=development`）では、実際の広告の代わりにプレースホルダーが表示されます：

```
┌─────────────────────┐
│   広告スペース      │
│ 本番環境では        │
│ 広告が表示されます  │
└─────────────────────┘
```

## 収益化のヒント

### 適切な広告配置

- ✅ コンテンツの間（自然な流れ）
- ✅ ページ下部（読了後）
- ❌ ヘッダー直下（邪魔）
- ❌ ボタンの真上（誤クリック誘発）

### 広告の数

- モバイル: 2-3個まで
- デスクトップ: 3-4個まで
- 多すぎるとユーザー体験が悪化し、収益も下がる

### レスポンシブ対応

`fullWidthResponsive={true}`を設定すると、画面サイズに応じて広告サイズが自動調整されます。

## トラブルシューティング

### 広告が表示されない

1. **AdSenseが承認されているか確認**
   - 審査には通常1-2週間かかります
   
2. **クライアントIDが正しいか確認**
   - `ca-pub-`で始まる16桁の数字

3. **広告ブロッカーを無効化**
   - 開発中はブラウザの拡張機能を確認

4. **サーバーを再起動**
   - 環境変数の変更後は必須

5. **本番環境で確認**
   - 開発環境ではプレースホルダーのみ表示

### 広告が表示されるまでの時間

- 初回設定後: 数時間～1日
- サイト追加後: 1-2週間（審査期間）

## ポリシー違反に注意

以下は禁止されています：

- ❌ 「広告をクリックしてください」などの誘導
- ❌ 広告の近くに誤クリックを誘発する要素
- ❌ 成人向けコンテンツ
- ❌ 違法コンテンツ

詳細: https://support.google.com/adsense/answer/48182

## 収益の確認

AdSenseダッシュボードで確認できます：
- 表示回数
- クリック数
- クリック率（CTR）
- 推定収益額

支払いは月8,000円以上から可能です。

## その他の広告ネットワーク

AdSense以外の選択肢：

- **Media.net**: Yahoo/Bingの広告ネットワーク
- **Ezoic**: AI最適化広告
- **独自のスポンサー**: 直接契約

実装方法は同じ（`<AdSense />`コンポーネントをカスタマイズ）。
